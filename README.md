# RealHunt Score

build RealHunt.co, example attached.

Build a clean, app-first SaaS platform called RealHunt.

This is NOT a listing portal. This is NOT an affiliate site. This is NOT a marketplace.

It is an AI-powered real estate intelligence engine.

Core concept:

Users paste any public real estate listing URL and receive a RealHunt Global Score™ (0–100).

The product must feel: • Minimal • Apple-level clean • Stripe-level simple • Bloomberg-level serious • Unicorn startup energy • Data-first • No clutter • No ads • No distractions

🔥 HERO SECTION

Headline:

Paste Any Listing. Get the Score.

Subheadline:

Know the Risk Before You Invest. Avoid expensive mistakes. Save thousands of euros and hours.

CTA:

Analyze a Property — Free

Secondary CTA:

See Example Report

Microcopy under CTA:

Free analysis. Transparent model. No paid rankings.

🔥 CORE MECHANIC

User pastes a URL from: Zillow Idealista Rightmove Airbnb Or any public listing

System extracts data signals and generates:

RealHunt Global Score™ (0–100)

Subscores: • ROI Potential • Market Stability • Demand Strength • Risk Level • Liquidity Outlook

Include a short AI explanation summary.

Score must feel like: "The Credit Score for Real Estate."

🔥 CRITICAL DIFFERENTIATOR

After the user receives their score:

Show:

“Better Alternatives Found by RealHunt Users”

This is NOT selling. This is intelligent cross-analysis.

Show 3–5 properties with:

• Higher score • Better ROI • Lower risk • Better liquidity

Label it:

You Might Be Overpaying. Here’s What Performs Better.

This creates intelligent cross-discovery without being a marketplace.

🔥 GLOBAL RANKING SECTION

Create a live Global Performance Ranking.

Top Performing Properties Worldwide Top Cities by Average Score Top Emerging Markets

Filter by: • Budget • Risk profile • Yield • Region

This ranking must feel: Objective Data-driven Independent

No sponsored positions.

🔥 VALUE PROPOSITION SECTION

Headline:

Don’t Buy Blind.

Text:

One bad investment can cost you €50,000. RealHunt is free.

Or:

Every property looks good in photos. Very few are good investments. We show the difference.

🔥 HOW IT WORKS

Paste the link

We analyze price, demand, growth, risk

Get your RealHunt Score

Compare with better-performing alternatives

Simple. Fast. Data-backed.

🔥 PRICING STRUCTURE

Free: • 3 analyses per month • Global Score • Basic summary

Pro: • Unlimited analyses • Advanced ROI breakdown • Comparable properties • Risk tier classification • PDF export • Portfolio tracking • Alerts when better opportunities appear

Pricing example:

€29/month

Position it like:

If one bad decision costs €20,000… €29 is not expensive.

🔥 UX INSTRUCTIONS

Design must be:

• Mobile-first • Big input box in hero • No walls of text • Clean typography • Subtle animations • Dark + light mode • Charts simple and elegant • No aggressive colors • Trust-focused

🔥 TRUST ELEMENTS

Include:

Transparent Scoring Methodology No paid placements No affiliate bias Data sources displayed Explain how score is calculated

🔥 TONE OF VOICE

Confident Calm Analytical Not hypey Not spammy Not salesy

Feels like: If Stripe built a real estate intelligence tool.
